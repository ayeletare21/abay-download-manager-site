## How browser integration works

1. Install and launch the Abay Download Manager desktop application.
2. From **Settings → Browser Integration**, install the ADM extension for a
   supported browser from its official store page.
3. The browser extension and desktop app connect locally through the browser's
   native messaging mechanism.
4. Choose a compatible media quality or ordinary download in the browser, then
   confirm the download in ADM.
5. Manage completed files in Library, play supported media, or create a local
   Media Studio project and export a new file.

The desktop application must be installed for the extension to perform an ADM
download. Browser integration is optional; direct Add URL and local Library
features remain available without it.

## Content and access boundaries

ADM works with compatible sources legitimately available to the user's browser
session. A supported service name does not mean every page or media item can be
downloaded. ADM does not provide DRM circumvention, access-control bypass,
paywall bypass, or access to private, paid, or restricted content that the user
cannot otherwise access. It does not promise support for every website or every
video format.

Users are responsible for ensuring they have the right or permission to
download, edit, export, and use content.

## Local-first workflow

Downloads, Library metadata, imported-file references, editing projects, and
exports are handled on the user's device. Imported source files stay in their
selected location. Non-destructive editing does not rewrite the original
source; export creates a new file at the destination chosen by the user.
