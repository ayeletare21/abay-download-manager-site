# Abay Download Manager website

Static GitHub Pages source for the Abay Download Manager product website,
privacy policy, support content, and terms.

Publication fields were supplied and approved by the owner on September 29,
2026. The policy and terms do not claim review or approval by a lawyer.

The site uses GitHub Pages' built-in Jekyll support and has no JavaScript,
analytics, cookies, trackers, ads, database, or external runtime dependency.

## Local review

Review the Markdown directly or serve it with a local Jekyll environment. The
planned production base URL is configured in `_config.yml` for the repository
name `abay-download-manager-site`.

Before publication, scan for unresolved fields, local paths, secrets,
development IDs, and tracking scripts. Commit to `main`, push to the separate
public repository, and enable GitHub Pages from `main` at `/`.
